# Plan v1: PoE2 Trade Monkey

Grundlage: `PROJEKT.md` (Scope), `DESIGN.md` (Optik), `CLAUDE.md` (Architektur, Regeln).
Fundament steht (Commits 16c494b, ae4c9e6): Seiten-Brücke, Storage, Feature-Host, Sidebar,
UI-Kit, aktuelle Suche, Stammdaten, Test-Kontext, Fixtures, 13 Feature-Stubs.

Jeder Task besitzt exklusiv seinen Ordner `src/features/<id>/`. Gemeinsame Dateien
(`src/ui`, `src/site`, `src/app`, `src/core`, `src/features/index.ts`) fasst nur der Orchestrator
an. Nach jeder Welle: `npm run check`, Live-Test in Chrome, Commit, Push auf beide Remotes.
